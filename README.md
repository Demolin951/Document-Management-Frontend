# Document Management Frontend
React + TypeScript frontend for the Document Management Web API.
This project provides a dashboard interface for managing documents, users, document versions and role-based document actions.
## Backend Repository
This frontend is designed to work with the backend API:
https://github.com/Demolin951/Document-Management-Web-API
## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Zustand
